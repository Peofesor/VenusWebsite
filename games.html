FenderBender - Boatmooring Simulator | Unreal Engine C++

A realistic simulation featuring force-based boat maneuvering and mooring mechanics. Players use controller inputs to navigate a reactive environment, interact with various points on the boat, and perform precise mooring maneuvers.

  • Boat Physics and Controls: Force-based controls with hydrodynamic effects such as prop walk, as well as realistic collision and damage zones where severe collisions can cause the ship to sink.

  • Mooring and Fender Mechanics: Physics-based rope handling to tie off the vessel, coupled with fully adjustable fenders that can be dynamically placed to protect the hull.

  • Interactive Cockpit: First-person character exploration with switchable camera angles and functional onboard displays/plotters. Features dynamic target indicators and UI menu adjustments.

  • Level Builder: Integrated a custom Weather Plugin, dynamic environment scenarios, and intelligent AI boat traffic requiring proper right-of-way reactions.

  • Living World & AI Vessel Traffic: Built using modular components (including integrated First 44 assets) and structured for multiplayer expansion to allow multi-crew operations.


Developed in Unreal Engine using both Blueprints and C++


My main contributions were:
  • force based restriction of boat when rope is cast in C++, exposing key elements to blueprints
  • visible ropes via unreal cable component
  • implementing all the interactions with ropes and cleats
  • leveldesign with realistic assets
  • project management
  • game design

This game was created as part of the 6th Semester project led by Prof. Dr. Klaus Ulhaas at the University of Applied Sciences Kempten.

Hunted Skies | Vektoria Engine C++

Fly above a procedurally generated island in this 3D action game. Choose from different planes, dodge enemy turrets, and fight hostile aircraft. Manage your fuel carefully – you only refill by taking down enemies. Run out of fuel, and you crash.

My main contributions were:

  • creating the turrets, which included calculating the shooting vector, their dynamic turning and alignment towards the player and the random turret spawning on the island
  • creating the landscape with the use of perlin noise
  • project management
  • game design

This game was created as part of the 3rd Semester GE-Lab project led by Prof. Dr. Tobias Breiner at the University of Applied Sciences Kempten.
